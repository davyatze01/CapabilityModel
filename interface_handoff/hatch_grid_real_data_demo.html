Cagliari hatch grid: millimetre (screen-constant) hatch

The real 2,180-hexagon Cagliari capability grid (from outputs/gpkg/Cagliari/Cagliari_hex.csv), reconstructed client-side from grid_params.json, rendered live with makeHatchGridStyleMM: a 45° line hatch whose spacing and width are set in millimetres (Very Low 9.5 → Very High 1.5 mm spacing in 2 mm steps, with a progressive 0.1 → 0.5 mm line in 0.1 mm steps). Because mm is a screen unit, the pattern looks identical at every zoom (more stripes just fall inside a hexagon as it grows) — and the legend on the right stays a FIXED size (so it drops into interfaccia's fixed legend slot) but redraws on zoom to show exactly how many hatch lines a cell of each level actually contains right now, scaled to fit the box. It's implemented as an OpenLayers CanvasPattern fill (a plain cached fill, not a per-feature custom renderer), which is the stable, flicker-free path — the reason earlier vector attempts were dropped for a PNG. Works over file://, just open this file directly.
